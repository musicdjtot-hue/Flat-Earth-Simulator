# Азимут-40 — 3D Карта Азимутальной Проекции и Поле Невесомости (Android 16–17 APK)

Интерактивный 3D-симулятор плоской Земли в азимутальной проекции (масштаб 1:1 км) с внешними материками за Антарктидой, Солнцем на 6 000 км, Луной на 5 000 км, границей невесомости на 38–40 км и сборкой APK под **Android 16–17 (SDK 36 / Capacitor 8)**.

## Вариант 1: Автоматическая сборка APK на GitHub (без установки Android Studio)
1. Загрузите **все** файлы и папки из этого архива (обязательно включая скрытую папку `.github/`, `scripts/`, `android/` и `src/`) в свой репозиторий на GitHub (удобнее всего через `git push` или перетаскиванием всех файлов вместе со скрытыми папками).
2. Перейдите во вкладку **Actions** вашего репозитория и выберите workflow **Build Android 16-17 APK**.
3. После завершения сборки (~2–3 минуты) скачайте готовый файл **Azimut-40-Android-16-17-APK** внизу страницы запуска.

## Вариант 2: Локальная сборка APK на ПК (Windows / Ubuntu / WSL)
Требования: Node.js 22+, Java JDK 21, Android SDK (API 36).
- **Linux / Ubuntu (WSL):**
  ```bash
  chmod +x build-apk.sh
  ./build-apk.sh
  ```
- **Windows:** запустите `build-apk.bat` или выполните в терминале:
  ```bash
  npm install --legacy-peer-deps
  npm run android:apk
  ```
Готовый файл появится по пути: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Настройки симуляции по умолчанию
- Граница невесомости: 38–40 км
- Видимость земель за Антарктидой: 85%
